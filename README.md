# UEEx World Cup Bot MVP

Telegram game bot for manual World Cup prediction orders.

## User commands

- /worldcup
- /myvote

## Admin commands

- /worldcup_FRA_BRA_1_20
- /confirm_O000123_1150
- /void_O000123
- /lock_WC0001

- /preview_WC0001
- /settle_WC0001
- /chatid
- /ping

## Render

Build command:

```bash
npm install
```

Start command:

```bash
npm start
```
